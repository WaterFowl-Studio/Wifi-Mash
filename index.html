How it works

The slider changes the number shown on screen. Start and Stop change the status message. None of these controls sends data over Wi‑Fi or uses a selected Mbps rate.

Network testing

For a real connection-speed check, use a reputable speed-test service. For load testing, use a test system you own or are authorized to assess, with clear limits and monitoring.
